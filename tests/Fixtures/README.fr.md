# Ressources de rendu

`fonts/NotoSans-Regular.ttf` et son fichier `OFL.txt` inchangé proviennent des exemples publiés de `PDFToolkit/pdf-fonts` v0.2.0, commit `4478c9d38549d8f3e8264a59505f4d9e1312eaf2`. La police est distribuée sous la SIL Open Font License incluse à ses côtés.

`images/rgba.png` et `images/rgb.jpg` sont des motifs originaux de `PDFToolkit/pdf-images` v0.2.1, commit `fd8b0f7bb9215817c83ea26ef5e3ba25ad77576f`, dans `examples/assets/images/`. Ils sont distribués sous la licence MIT de ce projet.

Les tests fournissent explicitement ces octets. Le convertisseur ne lit aucun chemin contenu dans le HTML et ne recherche aucune police système.
